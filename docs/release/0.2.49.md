# Blood Echoes 0.2.49

Adds a guarded depth/stencil pass-continuation experiment and more precise native frame diagnostics. The experiment is **OFF by default**; the existing adopted rendering configuration is preserved.

- Keep a Metal encoder open across eligible read-only-to-write depth/stencil layout changes when every other attachment/state field matches. Previous/current texture feedback, unknown resource access, barriers, fences, hoisted work, clears and render tails retain the original path. Write-to-read-only changes always retain their boundary.
- Keep per-pass visibility results identical: unknown callbacks and reduced-density production query targets cannot use the new continuation. No query buffers, texture allocation, resource budgets or cache capacities are added.
- Show the experimental switch in English, Simplified Chinese and Traditional Chinese. The launcher now has 34 Metal controls: 21 default ON and 13 optional experiments OFF. Existing explicit choices remain authoritative.
- Mark capture-initiated scheduler drains so recording-thread state changes are not confused with physical encoder transitions. Diagnostic recording remains opt-in.

## Validation and limits

The M4 native tests pass exact pixel and visibility-count comparisons with both held and direct encoding, candidate ON/OFF, attachment feedback (including later unbound aliases and parent views), barriers, tails, snapshots and query-policy fallbacks. The existing consumed-clear tests also pass with the candidate ON/OFF. Two isolated native SetHp death/respawn cycles completed without a new texture-format or Metal command-buffer failure; this is not enemy-combat or online coverage. CPU policy tests cover 355 cases. The ordered 80-patch Metal series reconstructs and remains idempotent. All 91 launcher tests pass (one platform-dependent skip), as do 38 Metal Python tests and 85 benchmark tests. Two stub launch tests required an unsandboxed rerun because the sandbox denied shell process substitution; the complete rerun passed.

A separate in-game diagnostic confirms three actual continuations in a captured frame; a separate fixed-view image spotcheck shows no new wall/floor/player/HUD loss. This is not whole-game visual validation. Scored comparisons omit capture/readback and GPU stage diagnostics; external recording state is unverified.

Eight same-binary interleaved runs measured 45.809 FPS OFF versus 45.814 FPS ON (+0.010%); the mean of per-run median footprints was 5745.04 versus 5772.42 MiB. Results and isolated lifecycle regression are recorded in [the evidence report](METAL-DEPTH-LAYOUT.md). No FPS gain is established, so this is an optional experiment rather than a performance promise. The 60 FPS target remains unmet in this scene.

No resolution, effects or cache capacity is reduced. Formal saves, preferences, game settings and caches are preserved. Private World Warper, development probes, test saves/routes and captured game data are excluded from release packages. Existing two-level addressing, motion/velocity handling, occlusion, memory patches, localization and online behavior remain in place.
