# Blood Echoes 0.2.45

Completes Save Manager. Current normal saves and active quick checkpoints are visible together, with file size, time and folder actions. Archive backups, older checkpoints and pre-F3 automatic backups have a separate history view.

Current normal saves and individual checkpoints support open-folder, backup and verified export. Exports preserve whole save structures, use new unique directories and never replace current files or pointers. Normal exports keep the existing savedata import layout; selected checkpoint exports include their manifest and pointer. Pre-F3 backups export as helper-compatible checkpoints. Unsafe export destinations inside live saves or backups are rejected.

Metadata refresh runs off the main thread and does not create saves, checkpoints or migration state. Browsing and opening folders remain available during play; backup, export, import and restore require the game to close. English, Simplified Chinese and Traditional Chinese are updated. Renderer, runtime hosts, networking, F3 behavior, Bundle IDs, caches and save budgets are unchanged.

Validation: 67 Swift tests passed, including 19 SaveStore tests. Cases cover read-only listing, active/history separation, unpublished F2 staging, complete normal exports, individual checkpoint backups/exports, pre-F3 compatibility, stale pointers, corruption, symlinks and unsafe destinations. Export selectors use asynchronous sheets attached to Save Manager; folder browsing never creates missing save directories. Further UI acceptance details are recorded with the release assets. UI acceptance uses a separate QA Bundle ID and synthetic saves; no QA progress or settings are promoted into the formal app.
