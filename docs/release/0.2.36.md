# Blood Echoes 0.2.36 (0236)

Some walls and floors can disappear when the community patch forces a lower
model LOD. The launcher and newly created M2 shortcut profiles now default to
**As in the game (0)**, and the launcher warns when Lower (1) or Lowest (2) is
selected. Existing choices are retained; select 0 and restart to repair an
affected configuration. No game assets or save data are modified.

An isolated Old Yharnam corridor comparison reproduced missing walls/floors at
LOD 1, restored them at the original setting 0, and reproduced the holes after
returning to 1. The test used native 1080p, MetalFX off and occlusion off.
Resolution and occlusion changes alone did not repair this save's rendering.

The inspected Nexus #163 V8 high-resolution fix is identical to the existing
Increased Graphics Heap Sizes patch; it is unrelated to the FPS preset. Its
bundled old FPS patches conflict with current FPS++ presets and are not added.
The larger-heap trial hit critical memory pressure on the 16 GB M4 and stopped
before visual validation. No heap increase or downloaded Mod payload is included.

A same-corridor ABBA comparison after the geometry repair measured native 1080p
at 63.01 / 62.08 FPS and MetalFX Quality (720p input, 1080p output) at 50.16 /
50.37 FPS. Mean process footprint medians were 5045 versus 5424 MiB. These are
fixed-camera M4 16 GB measurements, not whole-game results. GPU stage timing was
off and all scored frame times were retained. MetalFX is optional; a lower input
resolution does not guarantee a speed increase on the live scene-copy path.

The renderer library, two-level address table, velocity/motion-blur path,
occlusion implementation, resource lifecycle patches and cache capacities are
unchanged from 0.2.35. Bundle IDs, save/config locations, Chinese translation
support, F3 restart handling and launcher/game icons are retained.

Validation: same-save visual A/B/A, existing patch and launcher tests, native
Swift launcher tests/build. See the user guides for model-detail guidance and
the distinction between high-resolution heap fixes and FPS patches.
