# Blood Echoes 0.2.34 (0234)

Renames the maintained project and launcher from Bloodborne Optimized to **Blood Echoes**.
Repository: https://github.com/WiredThings/blood-echoes
Installed application: `/Applications/Blood Echoes.app`

The app menu, launcher title, Help/About links, current documentation, source build outputs
and Release filenames use the new name. Historical releases retain their original filenames;
upstream project names and credits are preserved.

Compatibility identifiers stay unchanged:
- Launcher: `io.github.bbport.optimized`
- Game: `io.github.bbport.optimized.game`
- Existing preference keys and `~/Library/Application Support/bbport` paths

No game, save, setting or shader-cache migration is performed. Runtime/renderer instructions,
F3 restart lifecycle, Hunter's Mark launcher icon and game-cover icon are unchanged.
The independent game window continues to be Bloodborne.
