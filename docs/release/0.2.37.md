# Blood Echoes 0.2.37 (0237)

Adds **optional, default-OFF The Hunter’s Dream online support** on the Metal backend.
The launcher handles website/device sign-in and stores the token in macOS Keychain.
Online mode creates a separate save copy on first use; later online progress stays in
that copy. Existing offline saves, settings, caches and quickload preferences are retained.
F2/F3 quicksave and quickload are disabled while online to avoid rolling back online state.

An isolated CUSA03173 1.09 client with community Simplified Chinese completed device
authorization, displayed the in-game server announcement and played bloodstain phantoms.
The user verified chalice **search → join**. A test note was created, listed and deleted
with permission, without independent second-client delivery verification. **Direct glyph
lookup, co-op and invasions remain unvalidated.** Account sign-in alone is not an online
gameplay test, and no PS4 crossplay compatibility is claimed.

The online dylib loads only when online mode is enabled. Tokens are limited to approved
The Hunter’s Dream HTTPS destinations, stripped on redirects outside them and omitted
from credential-header diagnostics. Certificate verification is enforced for the service.
Old offline-only HTTP/network-choice patches are rejected if their writes conflict.

The Metal rendering library and Vulkan compatibility binaries are retained from 0.2.36.
Resolution, effects, cache capacity, two-level page table, velocity path, occlusion and
resource-reclamation code are unchanged. There is no accepted offline FPS/memory A/B:
the first attempted benchmark stopped on swap-growth protection, so no measured
zero-regression claim is made. Offline load gating has automated regression coverage.

The launcher, Metal host and network module are rebuilt from the committed public source
export. Build documentation and scripts include the optional module; the source asset
also includes pristine pinned OpenSSL, Protobuf, MiniUPnP and nlohmann/json sources.
This release does not claim a new complete rebuild of the unchanged graphics dependencies.
bbnet/shadPS4/bbhost authorship and all dependency licenses are retained.

Release checks: 44 Swift launcher tests and 25 Python/runtime/packaging tests passed from
the public source export. Both packaged Metal hosts pass eager-binding usage checks;
the network module passes a certificate-verified public HTTPS request without a token.

Installation: quit the old launcher/game, extract `Blood-Echoes-0.2.37-macOS.zip`, and
replace the complete application. Bundle IDs and user paths are preserved. QA credentials
and test saves are not bundled or migrated; sign in again in the installed application
if you choose to enable online mode. The app remains ad-hoc signed and not notarized.
