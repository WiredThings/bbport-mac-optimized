# Bloodborne Optimized 0.2.31 (0231)

Removes the incorrect official-Chinese resource check and warning. **Official Chinese** uses
built-in game resources through region unlock; it does not require an external font or translation
package. Only **Community retranslation** imports the separately downloaded GOTY package. An
imported, verified package shows ready without a missing-font warning.

QA-only application identifiers can now be unique per run, avoiding LaunchServices selecting an
older test app. QA application data is restricted to `/private/tmp`; a missing or protected-path
preview override falls back to an isolated temporary directory. Production paths are unchanged.

The community import/overlay implementation from 0.2.30 is retained. No translation payload,
game assets, saves or private QA tools are distributed. Runtime/renderer bytes and graphics,
velocity, occlusion, page-table and memory patches are unchanged.

Validation includes the launcher test suite, Chinese/English visibility, independent Simplified/
Traditional packages, an actual GOTY ZIP import through the launcher, official/community switching
and private-folder isolation. Tests use an independent game copy and save directory.
The game-menu visual check was stopped after rapid swap growth; game rendering is not claimed
as verified by this acceptance run.

and [credits](../THIRD_PARTY_CHANGES.md#game-language-and-community-patches).
