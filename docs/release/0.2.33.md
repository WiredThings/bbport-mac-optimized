# Bloodborne Optimized 0.2.33 (0233)

The game application's default icon now uses the same rounded, padded Bloodborne cover
as the runtime icon. This removes the Hunter's Mark placeholder briefly visible during
F3 restart. The outer launcher retains its Hunter's Mark icon.

The normalized ICNS and attribution are included in source builds; the original game
icon file, game data, saves and private QA tools are excluded.

Runtime/renderer instructions and supervised restart behavior are unchanged from 0.2.32.
The owner confirmed repeated in-game F3 restarts do not accumulate Dock tiles in 0.2.32.
Validation for this update checks all icon sizes, alpha/margins, distinct launcher/game
artwork, nested bundle signing and preservation of runtime, renderer, settings and saves.
Full in-game visual acceptance of this icon-only update remains separate.
