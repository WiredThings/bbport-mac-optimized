# Blood Echoes 0.2.38 (0238)

Formal online and offline play now share the selected game save directory. The first migration backs up both existing formal save sets; when online mode is selected it continues legacy formal online progress, otherwise it keeps the normal formal save. Legacy folders are retained. **QA saves never participate in formal migration or default save selection.**

Going online verifies and archives game saves and all checkpoints before clearing active quicksaves. F2/F3 remain disabled for the entire online-mode launch. Returning offline creates a fresh checkpoint from the current committed normal save; it cannot silently restore a pre-online checkpoint. Ordinary autosaving and the user's offline quicksave preference remain intact.

A native **Save Manager** offers full backups, imported `savedata` backups, verified exports, normal-save restore, offline checkpoint restore, and folder access. Every restore first preserves the current progress. Hashing uses bounded reads, replacement swaps complete directories atomically, and the game holds the same save lock online and offline. Backups are not automatically pruned.

Online settings retain **The Hunter’s Dream** as the only service. There is no custom-server entry. Existing THD sign-in remains compatible. The device code is a click-to-copy button with feedback.

The Metal renderer, Vulkan fallback, render resolution, effects, caches, localization and the 37 Metal adapters are unchanged. Launcher, game host and network module are rebuilt; no whole graphics dependency rebuild or new frame-rate improvement is claimed. Paired co-op/invasion remain unvalidated.

Validation: 51 Swift launcher tests, 26 Python/runtime/packaging tests and 5 native quicksave cases passed. Save Manager backup/restore and online checkpoint clearing were exercised on synthetic isolated saves. No formal gameplay session or paired multiplayer test is claimed.
