# Bloodborne Optimized 0.2.32 (0232)

Fixes repeated Dock entries during quickload/restart on macOS Metal. The previous runtime
replaced an active Cocoa process with exec; the new lightweight supervisor waits for the
old process to exit before starting another. Quickload restoration is forwarded once.
Failures and termination remain final, and the existing mod/Chinese overlay cleanup runs
between launches. Save locking and normal autosave are retained.

The game now has its own nested application bundle with fixed identifier
`io.github.bbport.optimized.game`. Its game-cover icon formatting is retained.
The launcher remains a separate application. This does not merge the launcher/game Dock
items or change the user's global Dock preferences. Existing historical items may remain
until removed from the Dock; the new process uses the stable application identity.

The rendering library is unchanged: no graphics settings, shader/cache budgets,
velocity, occlusion, two-level page table or memory-reclamation behavior changes.
Official/community Chinese resources and user settings are preserved.

Verification covers native restart exit statuses, old-process termination, one-shot quickload,
normal/error exit handling, signal forwarding, real bundle identification/relocation,
and community-overlay cleanup over repeated restarts. The test harness uses no game or save
files. Full in-game F3 acceptance remains a separate check.
