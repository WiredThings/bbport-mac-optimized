# Blood Echoes 0.2.44

Fixes F3 restoring its checkpoint but stopping at Continue. The title screen can open a writable profile save before loading the character; a writable mount alone must not cancel automatic confirmation. Autoload now checks the verified Bloodborne 1.09 character-readiness gate before generating each menu tap and at save mounts. The existing 90-second timeout still returns control to the player.

F3 still restarts offline, removes network credentials and routes, and waits for the old process to exit. Both runtime hosts are rebuilt; renderer, online module, launcher controls, saves, settings and caches are unchanged.

Validation: seven native quicksave groups, including premature profile mounts, readiness changes during a tap, unmapped guest memory, timeout and online-to-offline restart. Isolated Metal gameplay reached the character automatically, then repeated F3 and returned to the same scene without manual confirmation. No new Vulkan gameplay test or paired multiplayer test is claimed.
