# Blood Echoes 0.2.48

This release promotes the validated Metal resource/vertex preparation work. Resolution, effects, cache capacity, Bundle ID, saves, iCloud sync and online behavior are preserved.

- Reject unsupported speculative vertex formats on the worker and retry on the ordered GPU path. Strict validation still rejects truly unsupported ordered formats.
- Derive exactly the required Metal vertex metadata from fetch-shader metadata; avoid raw guest-descriptor reads that provide no consumed fields.
- Skip dynamic vertex arrays, sorting, hashing and arena copies on static-input backends where the existing consumer never uses them. Vulkan dynamic vertex input remains unchanged.
- Continue compatible passes after consumed clears; notify snapshot versions for ordered GPU query writes; reapply guest traps using the new memory permissions.
- Expose 33 Metal controls: 21 default ON and 12 experimental OFF. Restored alternatives and heap-release history priority remain available without claiming a proven gain. Invalid upload-elision and incomplete-alias reclamation proposals are not enabled.

## Measurements and validation

M4 / 16 GiB, unchanged 1080p settings and fixed camera, isolated save/cache. Two separate four-run comparisons measured 45.80→46.44 FPS (+1.41%, storage experiment ON on both sides) and 45.96→46.41 FPS (+0.98%, storage experiment OFF on both sides). Do not pool those configurations. This is a small fixed-scene indication, not a whole-game or 60 FPS guarantee. No visual automation or frame readback occurred inside scoring windows; external recording state was not verified.

Two long runs each completed 12 native map transfers. The old unused vertex-preparation path copied 4,800,566,693 bytes cumulatively; the new path copied zero. This measures CPU copy traffic, not RAM saved. Two pairs of controlled death/respawn cycles passed; they are not enemy-combat or online regressions. Memory differences varied by run; no consistent net-RAM reduction was established and caches were not reduced.

Native checks include 5,378 exact legacy/new vertex-metadata cases, unsupported-format and protected-descriptor tests, guest-resource lifetime checks and actual Metal pipeline/archive tests. Cold graphics-key loading created 160 keys without a fatal speculative-format error. Quality checks cover matching walls/floor/player/HUD in the tested fixed view, not every map.

The remaining bottleneck includes main-render GPU dependency/tile spans. Profiling does not isolate pure fragment bandwidth or vertex ALU. All 35 observed small writes and their synchronization remain intact; full read/alias coverage is unresolved.

Development World Warper, private game hooks, test saves/routes and game files are excluded from the installation package. Runtime diagnostics remain disabled unless explicitly requested. See [controls](METAL-OPTIMIZATION-CONTROLS.md) and [investigation evidence](METAL-RESOURCE-CHAIN-STATUS.md).
