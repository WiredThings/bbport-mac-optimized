# Blood Echoes 0.2.35 (0235)

Fixes Metal binary-archive writes that failed with `expecting fragment stage` /
`missing vertex stage` after a loaded archive gained new pipelines. Rendering itself
continued, but the updated binary cache could not be saved.

Loaded archives now supply lookup hits only. A save releases that object and builds a fresh
archive from the complete successful prewarm descriptor set, then atomically installs the
v2 file. Legacy archives and source/SPIR-V caches remain intact; an invalid input or failed
write does not delete the original. Private temporary read copies are cleaned up.

The descriptor ledger retains only existing function references and CPU pipeline metadata;
it is released before gameplay with the warm archive. Live PSOs, functions, texture/buffer
caches and cache capacities remain unchanged. No shader or rendering math is changed.

Metal pipeline-map keys are stored as serialized bytes, preventing padding changes during
C++ copies from creating duplicate PSOs. Persistence remains experimental and OFF by default;
existing preferences are preserved. A first enabled launch creates the new v2 archive from
existing prewarm data. No manual cache clearing is needed.

Bundle IDs, data paths, Chinese text selection, F3 restart supervision and both app icons
remain unchanged. No game files, saves, community translation payloads or private test tools
are included. This is an archive/correctness repair; no gameplay FPS gain is claimed.

简体中文：修复 Metal 读取旧管线归档后无法保存新增管线的问题。旧归档只读查找，
写盘时先释放旧对象，再从完整预热记录创建新归档。原归档、SPIR-V/MSL 缓存、存档和
设置均保留，不改变画质或着色器运算。首次开启归档后会自动生成 v2 文件，无需清缓存。

## Validation

- 15 native regression groups passed, including archive rebuild/reload, write-failure
  preservation, both fragment outputs, resource lifetime, two-level BDA, scene targets,
  strict vertex math, fragment uniforms, geometry and tessellation GPU correctness.
- Private read-only replay of existing 1.09 shader-cache inputs: 608 render variants and
  44 compute pipelines. The old implementation failed both writes; the repair wrote
  successfully and hit all 652 creations on the next load. The 32 tessellation/geometry
  cache entries outside this direct replay were covered by their synthetic GPU tests.
- A half-set → full-set run explicitly checked both saves and completed without a write
  warning. Full-set process peak footprint was 1,630.5 MiB before / 1,180.7 MiB after;
  the new binary archive was 21,097,344 bytes. These are isolated pipeline-replay results,
  not gameplay FPS or steady-state game-memory measurements.
- The original formal legacy archive remained byte-identical throughout validation.
