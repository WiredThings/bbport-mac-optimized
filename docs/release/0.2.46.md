# Blood Echoes 0.2.46

Bounds automatic save history and adds optional iCloud Drive syncing of latest normal saves. Save Manager keeps 3 previous checkpoints and 3 pre-F3 copies per title, plus 5 automatic archives. Active saves, manual/imported/migrated/conflict backups and entries marked Keep are protected. Equivalent automatic archives reuse a verified copy instead of accumulating copies with different checkpoint IDs. Cleanup stops on unfinished recovery, bad pointers or failed verification and does not run during play.

Enable normal-save sync in Save Manager and choose an iCloud Drive folder. Only complete latest normal saves sync; quick checkpoints, history, game files, caches, settings and credentials remain local. Per-device latest packages and causal version vectors preserve independent offline progress. Different progress requires an explicit selection; cloud imports back up local progress, rebuild checkpoints and keep play offline. macOS performs transfers after write handoff. Sync defaults off; existing save paths and other settings remain unchanged.

The renderer, runtime hosts, networking, resolution, effects, F3 behavior and cache budgets are unchanged. Documentation and English/Simplified Chinese/Traditional Chinese controls are updated. Full source and pinned dependencies are included in the source archive.

Validation: all 87 Swift tests passed, including the opt-in real iCloud Drive integration. The live case confirms every file uploaded after both first publication and replacement, checks complete payload hashes and readback, and leaves one latest package. Isolated UI checks passed for current normal/quick saves, conflict selection, preservation of the losing progress, Keep and 3/3/5 cleanup. Earlier native iCloud account errors (4355) remain surfaced to users without losing the local or queued copies; no account settings were changed. Two physical Macs and real iCloud conflict/download recovery remain untested. [SAVE_SYNC.md](../SAVE_SYNC.md) documents the format and limitations. QA uses synthetic data and does not read or migrate formal progress.
