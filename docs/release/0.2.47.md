# Blood Echoes 0.2.47

Turn on **Save Manager → Current saves → Sync normal saves**. The launcher automatically creates or opens **iCloud Drive/Blood Echoes Saves**. On another Mac using the same Apple account, enable the same switch. The folder picker and custom sync-path preference have been removed. Sync stays opt-in and defaults off.

If iCloud Drive is unavailable, synchronization reports an error and preserves local progress without creating a fake cloud directory. Existing unrelated files are never adopted or overwritten. Development QA uses a separate fake home. Latest normal saves remain the only synchronized payload; quick checkpoints, 3/3/5 history retention, conflict backups, F3/offline protection, credentials and renderer/cache behavior are unchanged.

Validation: all 89 Swift tests pass, including automatic folder discovery on a simulated fresh Mac, safe failure when Drive is missing, and real iCloud first/replacement uploads using synthetic data. Isolated UI acceptance confirms that first enable creates the fixed folder with no file dialog. The runtime, networking and renderer binaries are unchanged. Two physical Macs have not been tested. See [SAVE_SYNC.md](../SAVE_SYNC.md) and the localized user guides.
