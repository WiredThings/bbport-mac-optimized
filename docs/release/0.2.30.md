# Bloodborne Optimized 0.2.30 (0230)

Chinese game languages now expose a **Chinese text** selector: official Chinese through the
existing region-unlock patch, or **Supuritto's Bloodborne Chinese Retranslation** through the
GOTY English replacement. English and other game languages hide and deactivate this selector.
Existing settings retain official mode until the user changes it.

- Import the author's **GOTY zh-cn / zh-tw** ZIP or extracted folder. Simplified and Traditional
  packages are kept separately. Obtain them from [Nexus #146](https://www.nexusmods.com/bloodborne/mods/146?tab=files).
- Import only the six English US/UK menu/item/font assets, preserve the original dump, and
  verify the managed copies before launch. No network/account access is needed during play.
- Apply the translation as the last temporary mod layer, independent of the general Mods switch;
  non-text mods remain available. Switching language/source removes that layer on the next launch.
- Skip known region-unlock selections for the community route without changing their saved state;
  reject renamed external patches that collide with those addresses.
- No translation or font assets are redistributed: the author's permissions prohibit reuploads.
  The app and complete source archive contain integration code and synthetic tests only.

The Metal renderer, runtime binaries, velocity/motion-blur handling, occlusion, two-level address
table and memory patches are unchanged. This launcher/resource update makes no frame-rate claim.
No resolution, effects, cache sizes or saves are changed.

Validation: launcher tests; Python import/path-safety, runtime overlay, region-patch conflict and
existing launcher/mod regression tests; real GOTY 2.2 zh-cn/zh-tw ZIP CRC and published SHA-256
checks; isolated bundled-helper checks. Interactive UI acceptance is pending because the host
was locked during packaging. Renderer and runtime binary hashes are
compared with 0.2.29. Text rendering throughout the game is not exhaustively verified.
