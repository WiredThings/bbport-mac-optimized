# Blood Echoes 0.2.42

Fixes texture-cache reuse that could select a 2D backing for a 1D view, causing a Metal assertion and exit 134. Exact and memoized lookups enforce view compatibility. Same-layout dimensional changes preserve GPU-only pixels through the existing copy/rebind/deferred-release lifecycle; mismatched layouts are rejected as reuse candidates. No quality, cache capacity, archive format, networking, translation or save-management changes.

Validation: the old cache reproduces the Metal abort in a native test. Nine native regression groups and ten networking Python tests pass. Two isolated enemy deaths in `cummmfpk` returned to the lamp in the same process; the second reload exercised the new incompatible-candidate rejection. Post-respawn footprint settled around 5.41 GiB. This is a correctness regression, not an FPS/memory comparison; no new live online death test was performed.

The original crash log omitted the resource address and selection path, so the precise original live resource remains unconfirmed. A separately logged tessellation pipeline error remains outside this fix. See [mechanism and reproducible tests](METAL-DIMENSIONAL-TEXTURE-REUSE.md).
