# Blood Echoes 0.2.41

Metal background draw preparation now rejects unsupported numeric/data-format conversions and lets the ordered command path read the resource table again. This closes a deterministic failure where a transient readable buffer/image descriptor terminated the entire process with exit 23. Invalid worker results never enter the pipeline cache, and no replacement format or skipped geometry is used for recovery.

Fatal GPU assertions now include their thread and a bounded call stack. These diagnostics run only on failure. Normal save, F2/F3, networking, translations, rendering options and cache budgets retain their behavior; the existing disk-cache formats stay compatible.

The original live `data_fmt = 15` log had no stack. The real worker-path failure has been reproduced and repaired, but the original live caller and the exact resource-table lifetime transition remain unverified. This release does not claim that all rare crashes are resolved or claim an FPS improvement.

The same failure class was independently documented in [upstream PR #166](https://github.com/deadinside28/bloodborne_pc/pull/166), which the maintainer adapted into 0.6.

See [mechanism and regression commands](METAL-SPECULATIVE-RESOURCE-VALIDATION.md).
