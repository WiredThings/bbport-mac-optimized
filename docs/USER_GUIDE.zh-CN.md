# Bloodborne Optimized 0.2.33 使用指南

[English](USER_GUIDE.md) · [项目首页](../README.zh-CN.md) · [分支工作与第三方来源](THIRD_PARTY_CHANGES.md)

本指南对应 WiredThings 分支 **0.2.33（0233）预览版**。
[下载完整安装包](https://github.com/WiredThings/bbport-mac-optimized/releases/tag/v0.2.33)。
旧上游指南中的后端、硬件测试和默认值不一定适用于此版本。

## 环境与安装

- **Apple Silicon Mac、macOS 26 或更新版本、Rosetta 2**。
  启动器是 ARM64；Metal 路径的游戏和渲染器宿主是 x86-64，经 Rosetta 运行。
  本分支主要在基础款 M4 Mac mini（10 核 GPU、16 GB 内存）验证，不能据此保证其他机型帧率。
- 自行准备的解密《血源诅咒》文件，且**已经合并 1.09 更新**。
- 安装包自带 Python 和运行库，游玩无需 Xcode、Homebrew 或自行编译。

解压 `Bloodborne-Optimized-0.2.33-macOS.zip`，把 **Bloodborne Optimized.app** 放进“应用程序”后打开。
应用使用临时签名，未经 Apple 公证；若被拦截，可到“系统设置 → 隐私与安全性”对该应用选择“仍要打开”。
Rosetta 可通过 macOS 提示安装，也可在终端执行：

```sh
softwareupdate --install-rosetta --agree-to-license
```

更新时先退出游戏和启动器，再替换**整个 App**。存档和设置在应用外，会保留；
尝试新版本前可先备份重要进度。

## 准备游戏目录

启动器需要的完整目录应包含 `eboot.bin`、`sce_sys/param.sfo` 和 `dvdroot_ps4`，
`param.sfo` 中的应用版本应为 **01.09**。

如果本体和补丁是两个目录，先将本体复制到新的合并目录，再把解出的 1.09 更新**里面的内容**覆盖进去，
替换同名文件，包括 `eboot.bin`、`sce_sys` 和更新后的 `dvdroot_ps4` 内容。
原来两个目录可以保留。只选择 `CUSA…-patch`，或把补丁目录作为子文件夹塞进本体，都不算合并。

安装包不提供游戏转储、解密服务、更新数据或中文资源下载。
目录检查变绿代表元数据符合预期，不等于全部游戏资源已完整校验。

## 首次启动

1. 选择“游戏文件夹”，等待检查。
2. 设置启动器／游戏语言、输出分辨率和全屏状态。
3. 点击“启动游戏”（⌘R）；“停止”（⌘.）结束游戏。
4. 展开“高级设置”，调整后端、升频、特效、帧率、优化开关、模组和第三方补丁。

准备文件写入应用数据目录。首次启动和进入新区域仍可能发生资源加载、着色器或管线编译，
导致等待或短时卡顿。本版本没有预编译好全部场景的离线库；已有磁盘缓存会复用，已知管线会预热；此前未知的变体仍可在运行时编译。清缓存会重新触发首次编译。

## 启动器与游戏语言

“**启动器语言**”可选跟随系统、英文、简体中文、繁体中文，立即生效。
“**游戏语言**”独立设置，下次启动游戏生效；简体中文的 PS4 语言值是 **11**，繁体是 **10**。
此选项不改变配音。选择任一中文后才显示“中文文本”，可选官方区域解锁或社区汉化。
其他语言隐藏该选项；旧配置默认保持官方模式。

### 官方中文（区域解锁）

此模式使用游戏自带的中文文本和字体，不需要额外下载或导入字体包。

官方模式下，游戏语言为 10／11 时自动选择 **Lance McDonald（manfightdragon）、Kyo** 的
**Unlock Game Region** 补丁。原补丁在上游 XML 中已经存在，本分支新增的是与语言选择联动。
补丁通过 `patches.bin` 作用于准备后的启动镜像，保留原始游戏文件和原有 ×／○ 约定，不安装外部翻译包。
重启后日志应有 `Game language: 11`（或 10）及所选补丁中的 `Unlock Game Region`。
官方模式不会要求导入外置字体或翻译文件。

### 社区汉化（GOTY 英文替换）

1. 选择中文游戏语言，再将“**中文文本**”切为“**社区汉化**”。
2. 点击“**从 Nexus Mods 下载**”，从 [Supuritto 的官方文件页](https://www.nexusmods.com/bloodborne/mods/146?tab=files)
   获取 **Chinese Retranslation GOTY zh-cn（简体）**或 **GOTY zh-tw（繁体）**。
   不要选用于原生中文／日配的通用包；欧美年度版不会因此增加日语配音。
3. 点击“**导入 GOTY 汉化包…**”，选 ZIP 或解压目录，等待“**汉化包已校验**”。
   简繁包独立保存，分别选中对应游戏语言后导入即可。
4. 启动游戏。日志应出现 `Chinese source: community`、所选中文值，实际 `BB_LANGUAGE=1`。
   此模式使用英语（美国）槽显示汉化，不使用区域解锁。

只导入六个文件：`menu/{engus,enggb}/font.gfx`，以及
`msg/{engus,enggb}/{item,menu}.msgbnd.dcx`。
副本与 SHA-256 清单保存在 Application Support 的 `optimized-launcher/chinese-translations`，
不进入应用或仓库，更新应用后仍保留。每次导入建立新副本，旧导入保留；清理时不要删除仍被设置引用的目录。
导入器拒绝危险 ZIP 路径、链接、重复、缺失文件和可识别的简繁不匹配；每次启动前重新校验，
游戏运行时没有逐帧校验开销。纯英文槽、没有中文目录标记的包需自行确认选的是作者对应的 GOTY 简繁版本。

专用汉化层最后挂载，独立于总 Mod 开关，覆盖文本／字体冲突，其余 Mod 照常加载。
已勾选的同名 **Unlock Game Region** 仅在该次启动跳过，不改已保存选择；
其他名称的补丁若覆盖相同地址，会明确报冲突。切回官方或非中文语言后不挂载汉化层，恢复使用原始资源。
原游戏文件从未被替换，因而不需要通过备份恢复；存档、画质设置和现有渲染补丁不受此流程修改。

作者不允许转载其资源，因此启动器只集成导入和下载入口，不携带文本、字体或 Nexus 登录信息。
社区重译与港版原生中文的文本风格、质量属于个人选择，本项目不将主观优劣作为兼容性保证。

## 后端、分辨率与特效

“显示 → 分辨率”是**输出尺寸**。新建配置默认 1920×1080、关闭升频；已有设置会保留。
“高级设置 → 超分辨率 → 预设”决定 MetalFX 场景输入尺寸；
“场景渲染分辨率”显示包含取整后的实际值。

MetalFX 是**时域升频**。以输出 1920×1080 为例：

| 预设 | 场景输入 |
| --- | --- |
| 原生抗锯齿 | 1920×1080 |
| 超高质量 ×1.25 | 1536×864 |
| 质量 ×1.5 | 1280×720 |
| 平衡 ×1.7 | 1130×636 |
| 性能 ×2 | 960×540 |
| 超高性能 ×3 | 640×360 |

倍率作用于每个维度。游戏特效和模型细节独立设置；打开优化项不会自动关闭特效或降低所选分辨率。

“**游戏物体速度图（实验）**”将符合条件的游戏速度信息合入 MetalFX 的相机运动图，适用时默认开启，
会增加 GPU 工作和辅助纹理。走这条路线时，关闭“动态模糊”仍保留速度图生成，并绕过已识别的最终模糊通道；
不支持的绘制使用保守回退，未保证所有场景的时域效果。更改后需重启游戏。

“**Metal**”为默认后端；“**Vulkan（兼容模式）**”保留 ARM64 渲染器／KosmicKrisp 路径，
使用独立缓存和 FSR 3.1／TAA 选项。切换后端不转换存档。
HDR、RCAS／锐度、后台预上传和 Vulkan 验证层只在 Vulkan 下显示，原设置会保留。
Metal 的“**垂直同步／不同步**”对应实际呈现行为；旧 Mailbox／Immediate 名称不代表两种不同的 Metal 队列实现。

“帧率上限”填 0 表示**不再额外限帧**，不是最高 120 Hz；
选定的 30／60／90／解锁帧率补丁和呈现同步仍会影响实际帧率。
解锁模式使用可变时间步长，60／90 帧模式使用固定时间步长。

## Metal 优化开关

“高级设置 → Metal 优化”共有 25 项，默认 **20 项开、5 项可选实验关**，已有的明确选择优先。
悬停可看技术说明。

- **已验证**：依据相应检查／测量采用。
- **实验性**：单项游戏收益或更广泛覆盖仍不确定；部分默认开启项也使用此标识。
- **组合采用**：经过组合配置评估后保留，不表示每一项都单独测出了收益。
- **内存开销较高**：管线归档持久化有已观察到的内存成本。

五项可选实验是跨块快照、片元参数专用化、计算内核小参数写入、宽松浮点运算和二进制管线归档。
关闭归档持久化会忽略已有归档文件，不删除文件；启动编译归档对象回收是另一项优化，会保留活跃管线。
此前放弃的离线编译库实验已经移除。

依赖未满足时，子项的实际开关关闭，但其保存的选择不丢失。alpha 合并还需要实际启用 MetalFX。
“恢复建议的优化默认值”只重置这一组，不改游戏画质或存档。
速度图和“**遮挡剔除（实验）**”分别位于对应设置区；若物体或光照闪烁，可关闭遮挡剔除并重启。

内存优化保留有效缓存容量，预算计算不是进程 RAM 硬上限。
部分着色器／页表模式变化会使用不同缓存变体并触发编译。
详见[开关证据](release/METAL-OPTIMIZATION-CONTROLS.md)及[测量局限](THIRD_PARTY_CHANGES.md#measurements-and-limits)。

## 按键与快速存读档

手柄通过 SDL gamepad 映射。默认键盘后备键位如下，已有配置可覆盖：

| 操作 | 按键 |
| --- | --- |
| 移动／镜头 | W A S D／方向键 |
| ×：交互／○：闪避、奔跑 | 空格／左 Shift |
| □：道具／△：回血 | E／Q |
| L1：变形／R1：轻攻击 | 1／3 |
| L2：枪械／R2：重攻击 | R／F |
| L3／R3：锁定 | Z／C |
| Options／触摸板左侧／右侧 | Return／Tab／Backspace |
| 十字键上／下／左／右 | I／K／J／L |
| 移植版设置／快速存档／快速读档 | F1／F2／F3 |

设置浮层也可用手柄 **L3＋R3** 打开。启动器里的 F1／F2／F3 标签可以点击重映射；
部分键盘需要同时按 Fn／地球键。其他键位可在退出游戏后配置 `bbport.ini` 的
`key.<input>`／`pad.<input>` 项；保留已有其他配置行。

快速存读档**默认关闭**，先开启后才能使用。
快速存档请求游戏写入新鲜存档，等待磁盘写入完成后生成快照；
快速读档恢复最近快照并重启游戏，不是完整的内存即时存档。正常自动存档仍开启。
F9 保留给开发录制，公开包不包含私人的路线录制／回放工具。

## 超宽屏、模组与社区补丁

超宽屏提供 21:9／32:9 输出，自动选择相应分辨率补丁和内存尺寸，使用原生渲染并关闭升频。
不要再叠加相互竞争的外部分辨率补丁。提供选项不代表每个分辨率与场景组合都经过实机验证。

可选[超宽屏 UI 包](https://www.nexusmods.com/bloodborne/mods/202)需要另行下载。
开启超宽屏后选择解压目录，再启用“UI 修正”。启动器先备份要替换的 `.gfx`，再安装到游戏目录。
关闭修正或超宽屏会恢复先前文件，包括先前已存在的其他 UI 模组。
修改前先退出游戏；备份在 `optimized-launcher/ui-mod-backups`，不随发行包分发。
与运行时语言补丁不同，安装 UI 修正会有意改动受管理的游戏文件。

“高级设置 → 模组”管理自备模组，文件冲突时列表靠后的优先。
“第三方补丁”读取适用于 01.09 的 shadPS4 格式补丁；分辨率由显示设置管理。
Metal 速度图路径会拒绝已知会关闭速度图生成器的外部写入。
XML 保留作者信息，但“数据库中存在”不等于“本机已启用／验证”。

调试菜单／字体、自由镜头都是可选社区功能，不是公开版的自动游玩流程。
调试字体不随包提供。使用[字体模组](https://www.nexusmods.com/bloodborne/mods/253)时保留原目录结构：
字体位于 `dvdroot_ps4/adhoc/font/`，着色器位于 `dvdroot_ps4/adhoc/FontShader/`。
仅放入 `dvdroot_ps4/font/` 不符合当前运行时检查路径。
缺少字体会跳过调试菜单补丁，缺少着色器则菜单可能不可见。
公开包不带 World Warper 和私人路线／地图往返测试工具链。

## 文件位置

| 内容 | 默认路径 |
| --- | --- |
| 与已有 bbport 共享的存档根目录 | `~/Library/Application Support/bbport/user` |
| 设置、模组／补丁选择、准备文件 | `~/Library/Application Support/bbport/optimized-launcher` |
| 游戏设置与自定义键位 | `…/optimized-launcher/bbport.ini` |
| Metal 磁盘缓存 | `…/optimized-launcher/gpu-cache/metal1` |
| 最近游戏日志 | `…/optimized-launcher/out/last-run.log` |

启动器偏好使用 macOS 的 `io.github.bbport.optimized` 域。
“高级设置”中自定义存档目录会覆盖默认路径。隔离试用时，先复制存档文件夹再选择副本；
无需通过删除 App 或清空着色器缓存来处理存档。

## 常见问题与反馈

| 现象 | 检查方法 |
| --- | --- |
| 提示版本 01.00／选到了更新目录 | 检查合并后的 `eboot.bin`、`sce_sys/param.sfo`，选择完整目录 |
| missing folder / unsupported link | 检查 `dvdroot_ps4` 是否完整、目录层级是否正确、链接是否仍指向有效目标 |
| 游戏还是英文 | 重启游戏；核对游戏语言、文本／字体文件及区域补丁日志 |
| 首次或进入新场景卡顿 | 仍可能是资源加载或着色器／管线编译；保留缓存，用已热身场景比较持续性能 |
| 遮挡剔除后闪烁 | 关闭实验性剔除并重启 |
| 开过性能分析后变慢 | 正常游玩关闭 GPU 计时和帧统计；详细诊断自身会影响帧率 |
| 高内存、爆音或闪退 | 避免同时启动两份游戏；保留日志并反馈场景和运行时长。尚未宣称爆音／长时间运行问题已修复 |
| 完整 App 提示选源码目录 | 启动器设置中选择内置引擎；若缺文件，重新解压完整 ZIP |
| 帮助菜单打开了旧页面 | 更新至 0.2.33；帮助和关于入口已指向本分支，中文界面打开中文指南 |

请在[本分支 Issues](https://github.com/WiredThings/bbport-mac-optimized/issues)提供：
App 版本、Mac／内存、macOS、后端、输出与场景渲染尺寸／预设、特效、位置和相关日志片段。
可隐去私人路径，不要上传游戏文件或存档。公开包不包含本机 benchmark／分析脚本，运行时诊断按需开启。

构建源码见 [SOURCE.md](release/SOURCE.md)、[构建指南](release/BUILD-OPTIMIZED.md)及[第三方来源](THIRD_PARTY_CHANGES.md)。
0.2.33 标签和源码包保留为构建快照；当前分支文档可以包含后续勘误，不会因此改变已有安装包。
