# Blood Echoes 0.2.40

About now displays **0.2.40 (source Git short commit)** instead of repeating the version as a numeric build. The full project revision is embedded in `BBSourceCommit`; the macOS `CFBundleVersion` remains numeric. The settings page uses the same display identity.

Release builds resolve provenance from their own Git checkout or a Git-less corresponding-source manifest. They reject unknown identity and never borrow an unrelated parent repository commit. Source-build defaults and packaging metadata are updated accordingly.

Only this version is Latest. Older releases remain downloadable, with their tags and assets retained, and are marked Pre-release.

This is a launcher/build-metadata update. The game host, online module, renderer, graphics/cache policies, save/restore behavior, translations and user settings remain unchanged. The always-offline F3 policy from 0.2.39 is retained. No gameplay or performance improvement is claimed.

Validation covers 58 Swift launcher tests and 13 Python build-identity/packaging tests, including Git-less provenance, legacy manifests and invalid-identity rejection. The launcher is rebuilt from committed public source; unchanged runtime binaries are verified byte-identical.
