# Bloodborne Optimized 0.2.29 (0229)

[English user guide](../USER_GUIDE.md) · [中文使用指南](../USER_GUIDE.zh-CN.md) · [Third-party credits](../THIRD_PARTY_CHANGES.md)

## Changes

- Point the launcher Help/About homepage, guide, downloads and problem-report links to
  [WiredThings/bbport-mac-optimized](https://github.com/WiredThings/blood-echoes).
- Open the Chinese user guide for either Chinese launcher language; use the English guide otherwise.
- Update the English and Chinese installation guides, including the merged 1.09 game-folder
  layout, safe copy/overlay commands and missing-menu troubleshooting.

This is a launcher-only update. Runtime and Metal renderer binaries are unchanged from
0.2.28; there is no new rendering or performance change. Existing saves, settings, paths,
controller mappings and optimization selections are retained.

## Install

Extract `Bloodborne-Optimized-0.2.29-macOS.zip` and replace **Bloodborne Optimized.app**
in Applications. Requirements remain Apple Silicon, macOS 26+, Rosetta 2 and your own
compatible decrypted game folder merged with update 1.09. The app is ad-hoc signed,
not Apple-notarized. The previous 0.2.28 release remains available for rollback.

The app excludes game data, saves, shader caches, World Warper, recorded routes and private
development tools. The accompanying source archive contains the exact tagged source,
pinned dependencies and applied adapter patches. See [SOURCE.md](SOURCE.md).
