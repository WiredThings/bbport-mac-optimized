# Blood Echoes 0.2.43

Ports the 1D-image lowering from [shadPS4 #5133](https://github.com/shadps4-emu/shadPS4/pull/5133) to Metal: logical 1D/array images and their shaders now agree on normalized 2D backing. Compatible aliases share backing; layout, memo, lifetime and pre-backend checks remain. Adapter 0038's strict speculative/ordered numeric-format policy is unchanged.

Metal-specific coverage preserves linear border sampling, array LOD queries, gradients, offsets, dimension queries and atomics. Old shader caches remain on disk in their original namespace; no cache capacity or quality changes. The launcher executable, game hosts, networking module, Chinese patches, save management and Bundle IDs are unchanged; launcher version/source metadata is updated.

Validation: 28 SPIR-V/MSL cases, six native pixel comparisons, eleven native regression groups, ten networking tests and two isolated enemy deaths/respawns pass. Four fixed-camera ABBA runs average 56.97 → 58.08 FPS, within substantial run-to-run variation; no speedup is claimed. Mean median footprint was about 104 MiB lower without scoring-phase swap growth, but cache-history differences and resource-pool variation prevent claiming lasting memory savings. No new live online death test. [Implementation, measurements and limits](METAL-1D-IMAGE-LOWERING.md).
