# Blood Echoes 0.2.39 (0239)

Quicksave and online play no longer have mutually exclusive controls. Online entry archives old checkpoints and creates a new baseline from committed game saves. F2 can save in either mode. **F3 always restores offline**, with a new game process after the old one exits and with network credentials, module selection and host overrides removed.

After a quickload, retries, menu restarts and later launcher sessions stay offline until online is explicitly enabled again. A persistent marker in the selected save root is written before restore mutations; an interrupted or failed restore cannot silently reconnect. Manual online/offline switching seeds a new baseline, while an F3 retry preserves its original checkpoint. Server-side messages, statistics and completed online actions cannot be undone by a local restore.

Save Manager restores also switch to offline. Online baseline replacement is staged, verified and published atomically after old progress has been backed up. The public launcher never imports QA saves. Existing saves, settings, THD Keychain identity, translations and graphics optimizations are retained; no cache is cleared or resized.

The launcher and Metal host are rebuilt from the committed public source. The online module, renderer and Vulkan fallback remain unchanged. Synthetic-save and substitute-process tests cover online save → offline restore → repeated offline restore, credential removal, process reaping, crash-protection markers and localization-view restart handling. Validation: 54 Swift tests, 61 Python tests and six native quicksave cases passed. No new full gameplay or paired multiplayer validation is claimed.
